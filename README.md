# Восстановление клиента RF Online 455

Обновлено 11.11.2026. Сейчас **M6**, ориентир **25% (20–35%)**.
M9: поддерживаемые исходники и собственный RF_Online.bin с полным поведением
закреплённого 455, без модернизации графики. Полных областей принято **0/12**.

Только клиент, R3Engine и необходимые зависимости. Серверы — справочник
и предоставленная пользователем среда проверки. Их код/настройки не менять.
Оригинальные файлы не изменять, входные EXE не выполнять. Git локальный.

Учёт функций от 11.11. В IDA выделена 37 871 функция. Для 2 807 (+15) есть
адресные доказательства, для 1 018 (+17) сохранены полные листинги и графы.

## Практическая сеть

Пользователь запустил `E:/RFOnlineTrash/rf455-v0.4.0` и подтвердил вход
оригинальным клиентом из `E:/RFOnlineTrash/RFOnline`. Хеш этого BIN совпадает
с первичным эталоном, лаунчер совпадает с комплектом сервера.
Собственная сборка получила настоящий билет через лаунчер27831 и прошла
игровой вход27830: результат0, реальный список персонажей и живой кадр выбора.
Последующий реальный выбор существующего персонажа тоже принят сервером.
[Сеть и дальнейшая проверка](research/client455-live-launcher.md).
Учётные данные и ключи в репозитории не хранить.
