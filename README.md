## Где находится работа

| Путь | Назначение |
|---|---|
| scripts/native/ | Написанные и восстановленные модули C/C++, отслеживаются Git |
| scripts/ | Подготовка/перенос исходников, сборка, необходимые проверки; старые probe не являются очередью |
| config/ | Закреплённые входы, очередь и лимиты |
| research/, inventory/ | Исследования и доказательства с указанием условий |
| work/client455-port/ | Сохранённые клиентские исходники, современный проект и текущая сборка |
| work/client-reference/, work/recovered/, work/client-dependencies/ | Эталоны и необходимые зависимости |
| work/m9/102a2443/ | Проверенный комплект запуска и точка отката |
| work/shared-runtime-inputs/ | Общие неизменяемые копии ресурсов |
| local/ | Локальные зависимости инструментов |
| artifacts/ | Логи сборки, доказательства, компактный архив очистки |

Исходники и генераторы не перемещаем массово: это сломало бы действующие зависимости.
История прежних отчётов есть в Git; крупная история приёмки вынесена в docs/history/.
Игровые ресурсы, рабочие копии и IDA-базы не входят в Git; это локальные данные,
не удалённая резервная копия. Сервер и оригинальные установки не изменяются.

## Поддерживаемые команды

Из корня workspace в PowerShell:

```powershell
./scripts/Invoke-Python.ps1 scripts/workspace.py status
./scripts/Invoke-Python.ps1 scripts/workspace.py verify
./scripts/Invoke-Python.ps1 scripts/preview_client455.py --check-inputs
```

Проверено: бюджет хранения, целостность текущего bin/линковки и 2016 входов запуска.
Эти команды не входят в аккаунт и не запускают игру.

workspace.py build — последовательный путь инкрементальной сборки с сохранёнными
зависимостями; воспроизведение с чистого каталога ещё относится к BASE-02.
scripts/Preview-RF455-1080p.cmd — ручной запуск проверенной собственной сборки;
нужен поднятый сервер и ввод тестового аккаунта. Пароли в файлах не сохранять.
