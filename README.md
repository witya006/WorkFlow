## Практическая сеть

Пользователь запустил `E:/RFOnlineTrash/rf455-v0.4.0` и подтвердил вход
оригинальным клиентом из `E:/RFOnlineTrash/RFOnline`. Хеш этого BIN совпадает
с первичным эталоном, лаунчер совпадает с комплектом сервера.
Собственная сборка установила TCP-соединение с 127.0.0.1:27830.
Отдельный лаунчерный обмен на 27831 принял тестовый аккаунт и вернул игровой
ключ. Это ещё не игровой вход собственного BIN.
[Сеть и дальнейшая проверка](research/client455-live-launcher.md).
Учётные данные и ключи в репозитории не хранить.
