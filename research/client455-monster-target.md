# Проверка 205 — запрос HP и гибель монстра

При выборе цели 455 по RVA `0x12ea70` вызывает отправителя
`0x18bf00`. Запрос `13/26` состоит из восьми байт. Для монстра
это тип объекта 0, вид 1, WORD серверного индекса и DWORD серийного
номера. Снятие выбора отправляет `13/28` с одним байтом.

Сообщение `3/24` содержит семь байт с индексом, серийным
номером и кодом причины. Обработчик по RVA `0x1664a0`
находит монстра по серийному номеру, обновляет серверный индекс
и вызывает его виртуальный метод `0x5a630`. Код 0 подготавливает
нулевую долю HP и переводит монстра к завершению гибели.
Старый клиент маршрутизировал этот номер в появление другого игрока.

Оригинальная обработка положительного попадания по RVA `0x47210`
применяет ожидаемое значение HP на последнем кадре через `0x47900`.
В клиенте добавлены запрос при выборе монстра, отмена подписки при
снятии выбора, маршрутизация `3/24` и применение доли к финальному
кадру обычного попадания. Промежуточные кадры многокадровой обычной
атаки требуют отдельной сверки.
[Хеши обоих эталонов и адресные доказательства](../inventory/client455-monster-target-reference.json)

В первом прогоне сборки `6c3ce827…` камера не выбрала цель.
Во втором на NeutralB получены `13/29` с нулевой долей и `3/24`
для монстра 1032089. На кадре видны число 22 и сокращение
шкалы HP. Доля в объекте монстра достигла нуля в этом кадре.
После гибели клиент выбрал другого монстра.
Остаток стрел изменился с 312 до 311.

Тот прогон показал два дефекта. При неизменной цели повторные
вызовы установки цели отправили 172 запроса. Ответ локального
сервера имел 11 байт, короче полного формата эталона. После
первого выстрела аватар остался в мирном режиме с установленным
флагом запроса, поэтому повторная команда не отправила новый выстрел.

В следующей сборке запрос HP привязан к смене выбранного монстра.
Для 11-байтового ответа принимаются проверяемые поля общего начала.
Исходящий запрос боевого режима восстановлен по RVA `0x18c300`.
Он отправляет `13/21` с режимом и флагом из состояния игрока.
В `4/25` эталон читает режим из бита 1 и флаг из бита 13.

Сборка `cb2c9c628275954cf5110c65dda00efe56ff02d2ca8c04c995917a765ba18b9f`,
x86, RVA входа `0x18a660`, прошла два выстрела за один вход
на NeutralB. Зафиксированы один запрос боевого режима, три
выбора цели и три ответа HP. После первого попадания промежуточный
выбор сбросился до выстрела. Причина сброса требует сверки.
Следующий выбор привёл ко второму выстрелу. У монстров 1032091 и 1032092 подтверждены
22 урона, `13/29` с HP 0 и `3/24`. На обоих кадрах видны
число 22 и сокращение шкалы. Остаток стрел изменился с 310 до
309 и затем до 308. Необработанных исключений нет.

Открыты попадание по выжившему монстру, промежуточное изменение HP
при многокадровой обычной атаке и полный ответ для других типов целей.
