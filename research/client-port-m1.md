# M1: R3Engine собран под VS 2026 x86

2026-11-04: получены успешная полная сборка и две последующие чистые пересборки.
Собраны 58 C++ файлов и RC, R3Engine.lib — архив из COFF x86 объектов. Итоговый SHA-256
и SHA-256 всех 58 объектов находятся в inventory/client-build-result.json.
Критерий компиляции/архивации M1 выполнен; поведение и линковка RF_Online не проверены.

Среда: VS 2026 18.11.3, MSVC 19.51.36260.0, v145, Windows SDK 10.0.26100.0.
DirectX 8.1b SDK получен из архива публичного выпуска; хеш совпал с метаданными,
подпись Microsoft действительна. Установщик не запускался. Версии и хеши:
inventory/directx81b-sdk.json, подготовка scripts/prepare_dx8_sdk.ps1.
Используется overlay 13 оригинальных DX8 headers: полный старый Include конфликтовал
с Windows SDK через устаревшие системные заголовки. Библиотеки SDK извлечены отдельно.

Патчи в рабочих копиях: cjcache/commonutil/r3profiler — явная область видимости
переменных; r3bsp.h/bsp.cpp — явный void для ClearVariable (оба найденных вызова игнорируют
результат). Полные точные байтовые преобразования: scripts/apply_client_port_patches.py.
Хеши до/после в inventory/client-source-patches.json. Исходные материалы не менялись.

Для остальных циклов временно применён /Zc:forScope-: его действие проверено отдельной
маленькой компиляцией. MSVC предупреждает об устаревании; флаг требуется заменить
явными объявлениями в последующей очистке. Используются /MD, C++14 и /EHsc.
Кодировка строк, FP-совместимость и CRT ABI ещё не доказаны. Это не готовая библиотека
для подстановки в старый клиент по одному совпадению имени.

Предупреждения о небезопасном CRT и старых объявлениях SDK сохранены в локальных логах.
Сборка статической библиотеки допускает внешние символы: Character/JPEG/Miles и другие
контракты клиентской линковки должны проверяться отдельно в M4.

Воспроизведение: prepare_client_build.py → apply_client_port_patches.py →
prepare_dx8_sdk.ps1 → build_client_engine.ps1 -DirectXInclude <overlay> -CleanRebuild.
Большие материалы и логи находятся в игнорируемых work/local/artifacts и требуют backup.
