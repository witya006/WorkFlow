# Запросы и ответы обычного торговца, 15.11.2026

Закреплённый 455 x86, база `0x400000`, SHA-256
`b1b5febf0d0394712e2322350e19dafe60742e8642697b93cfb89135bac1fd8b`.
IDA сессия проверки закрыта. Пакеты отправляет штатный клиентский
транспорт через RVA `0x197F30`, группа 12.

| Операция | RVA | Подтверждено в машинном коде |
| --- | --- | --- |
| Покупка | `0x1981D0`, `0x1983D0` | Подтип 1, размер `9+6*n`. Торговец u32 в 0, число записей u8 в 4, записи с 9. Запись состоит из кода хранилища u8, слота каталога u32 и количества u8. |
| Успех покупки | `0x198430` | Подтип 2, баланс Dalant и Gold в 0 и 8. Число подтверждений в 65. Запись с 66 имеет ширину 7: серийный номер u16, тип модификатора u8 и значение u32. |
| Отказ покупки | `0x198820` | Подтип 3, баланс в 0 и 8, причина в 36. |
| Продажа | `0x198AD0`, `0x198C80` | Подтип 4, размер `9+4*n`. Та же шапка, запись состоит из кода хранилища u8, серийного номера u16 и количества u8. |
| Итог продажи | `0x198CC0` | Подтип 5, успех в байте 0 равен 1. Новый баланс в 1 и 9, причина отказа в 34. |

RVA `0x0790E0` преобразует код хранилища 1 в 8 для типа 46,
в 2 для остальных типов от 9, сохраняет 1 для типов 0–8. Остальные
входные коды проходят без изменений. После успеха покупки RVA
`0x137110` передаёт предмет выбранному владельцу по сохранённому
номеру сумки и ячейки. Код покупки отправляет слот каталога,
серверный идентификатор из ответа принадлежит экземпляру в сумке.
