## Сверка с 455

В обоих закреплённых x86-эталонах по RVA `0x159e20` конструктор
сохраняет два пути, `%s\KeyMap.dat` и `%s\KeyMap_NKM.dat`.
Префикс возвращает функция `0x1e5b50` через `0x1e5b70`.
Селектор `0x15a320` выбирает один из двух путей по полю настроек,
затем передаёт путь загрузчику `0x15a360`. Последний читает семь
секций через `GetPrivateProfileStringA`.

В старом исходнике жёстко задан `./DataTable/KeyMap.dat`. В поставке
455 этого файла в корне нет. Для основной раскладки подставлен уже
восстановленный локализованный корень `RF455_GetClientDataRoot()`.
Переключение на NKM, новые секции и полный набор действий 455
остаются открытыми. Сессия IDA сохранена и закрыта.

## Способ проверки

Скрытый собственный клиент использовал обычный путь
`CInputProcessMgr::InputProcess_Keyboard → CAvatar::RequestMoveByKeyboard`.
Тест на одну секунду выставлял состояние штатной стрелки вверх
непосредственно перед опросом клавиш. Windows применяет
`SetKeyboardState` к таблице вызывающего потока. После каждого
опроса исходное состояние восстанавливалось.
[Документация Windows](https://learn.microsoft.com/en-us/windows/win32/api/winuser/nf-winuser-setkeyboardstate)

Флаг `--observe-walk` включает этот тест на локальном сервере в обычной
сборке. Подтверждение из реального устройства ввода и управление
мышью требуют отдельного прогона.

## Результат

Загружены 24 назначения из штатного `zh-tw/KeyMap.dat`,
движение вперёд привязано к `VK_UP`. Нажатие зарегистрировано
через 469 мс после стартового `3/2`, отпускание через 1453 мс.
Клиент поставил в очередь два сообщения `4/1` и одно `4/12`.
Входящий ответ именно на эти сообщения пока не сопоставлен.

Аватар прошёл 73,94 единицы. После отпускания он продолжал идти
до цели. На отметках 6516 и 8516 мс его координаты совпали
с точностью записи, а действие вернулось в исходное состояние.
Привязка камеры следовала за аватаром во всех шести замерах.
Углы камеры не менялись. На игровом кадре при движении
видны аватар и местность. Прогон завершился по таймеру без
фатального исключения. Временный файл входа удалён.
