# Возврат к выбору персонажа после отказа сервера

13.11.2026. Исправлен потерянный переход: отказ выбора оставлял порт
в `LGS_JOINGAME`, поэтому следующий вызов «Войти» ничего не отправлял.
Теперь отказ показывает локализованное сообщение и возвращает
`LGS_CHARACTERLOBBY`. Успех и отсутствие ответа сохраняют прежний маршрут.

## Основание

Сохранённый листинг вторичного эталона 455:
SHA-256 `46528aac20499e3b3928d58658d7e0cefe26feba7cd193796d5cfbf7a2bbc558`,
x86, image base `0x400000`, RVA `0x13e18f–0x13e2d5`.
Ветвь результата выбора использует 72 → NDLanguage 2779,
74 → 3732, 76 → 3816, остальные отказы → 521. Результаты 0 и 255
не возвращают выбор; 0 посылает moveout type 1.
Все остальные результаты присваивают исходному состоянию значение 12.
В порте использовано имя `LGS_CHARACTERLOBBY`, а не число из чужого enum.

Исходная выгрузка IDA хранится в игнорируемом
`artifacts/client455-progress/selection-rejection-reference/diagnostic.json`.
Новая полная эквивалентность функции этим анализом не заявляется.

## Проверка

На старой `bade4e5c…` новый тест воспроизвёл потерянный переход для
результата 72: [до исправления](../inventory/client455-selection-rejection-before.json).
В собственной x86-сборке
`d0a3edbf5b532ce85c4fc0cb76056e139add6287ee83a2ee13604204be3fcec7`
(image base `0x400000`, entry RVA `0x1a5430`) проверка прошла.

Это реальные объекты текущего клиента, отдельное скрытое окно
1920×1080, настоящие шрифты и элементы сообщений. Внешняя граница
сервера заменена управляемыми зашифрованными ответами; входа на сервер нет.

- Настоящий `EventJoinGameFunc` отправляет выбор слота и включает ожидание.
- Фрагментированный ответ проходит обычный диспетчер и `NetworkInput`.
- Коды 72, 74, 76, 1 и 254 возвращают выбор, показывают правильный текст,
  не отправляют переход в мир и потребляются один раз.
- Enter подтверждает сообщение; следующий callback отправляет новый запрос.
- Успешный ответ после отказов отправляет обычный moveout 1/5 с type 1.
- Проверены русская и корейская локализации. Код сетевого формата не менялся.

[Результат](../inventory/client455-selection-rejection.json).
Живой отказ сервера, физический ввод в полной сцене и весь маршрут
входа этим компонентным прогоном не приняты. M6/M9 остаются открытыми.
