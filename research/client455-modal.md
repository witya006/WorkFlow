## Изменения в обычном клиенте

Обе кнопки теперь используют common.spr action1: normal0, hover1, pressed2,
disabled3. В реальных корейском и русском ресурсах все эти кадры имеют размер
67×21; старые42×39 и разные наборы Yes/No удалены. Подписи берутся из
NDLanguage106/107, используют outline32 и центрируются по метрике текущего
GDI-шрифта. Отключённая подпись получает FF797979 независимо от hover.

Фон окна теперь222628, исходная alpha D8, outline6A6E72. SetAlpha сохраняет
RGB фона. Геометрия рамки перенесена из CGUIOutlineBoard: толщина1, отступ2.
Текстовая область центрируется в полном фоне; кнопки находятся внизу справа
с отступами7. Scrollbar получил подтверждённые кадры action2: arrows0/1,2/3,
thumb5×18 и цвет70635D. Его общий layout/input алгоритм пока остаётся старым.

При Open восстанавливаются только подпись106 и доступность OK; подпись Cancel
может сохранять назначенный вызывающим кодом текст. В старом GUI этот порядок
не воспроизводился. Новые значения проходят через обычные методы клиента,
без отдельной декоративной реализации диалога.

Enter возвращает1. Esc возвращает **3**, только если разрешено закрытие;
при запрете возвращается0 без события. Целевой базовый конструктор начинает
с запретом Esc. Wrapper выставляет параметр явно; он также сбрасывается при
повторном использовании окна из pool. В create-info добавлен именованный
`bAllowClose455` с обычным значением TRUE.

Y/N принимаются только в style3 и подавляются, когда основной chat input
имеет focus и одновременно show/active/enable-focus. Использован настоящий
legacy chat-input provider; его соответствие полю нового MainGame455 ещё
подлежит полной проверке при переносе этого stage. События мыши сохраняют
результаты1/2/3. Вложенному диалогу ввод передаётся раньше родительского.

Измерение подписи добавлено в текущий GDI-provider через
`RF455_MeasureLegacyText`. FreeType/ANSI и точная метрика всех ветвей455 остаются
открытыми. Глобальное поведение старого CGUITextBoard не переименовано в455.

## Проверки и результат

`probe_client455_modal.py` скомпоновал собственный console entry с настоящими
обычными клиентскими объектами. Пройдены Korea/Russia: реальные языковые пакеты
и спрайты, пять состояний кнопок, размеры, подписи, цвета, рамка/отступы,
Enter/Esc/Y/N, nested dialogs, фокус настоящего chat input, повторный pool,
сброс OK при Open и mouse observer/result1/2/3. Естественный exit0 в обоих случаях.

Собственная probe PE SHA-256
`d3ca9b9bc5781e4e75c9460d54ea52c93f514a0d9a71f33d5f8d621611442615`,
entry RVA E3700. Сохранены кадры normal/hover/disabled для двух профилей,
только viewport640×480. Normal содержит20000 изменённых пикселей. Корейский
и русский кадры осмотрены: подписи читаемы, старый посторонний значок исчез.
Исходные изображения находятся по путям из `inventory/client455-modal-native.json`.
Это проверка восстановленных элементов, не пиксельная приёмка всего GUI455.

182 клиентских TU,20 canonical kernels и24 facade TU собираются. Полная
линковка:0 unresolved, без CharacterMR и /FORCE. Новая production PE SHA-256
`a5b1da0b344c898c6b71079b64742ee08852e62eaaf7e206e55815540615d994`,
x86, base400000, entry RVA14D300, размер2023936байт.

Затронутый GDI/Unicode путь повторно проверен на Korea/Russia: независимый
GDI oracle, atlas, нормальный CGUIText и совпадение кадров через wide bridge
прошли. Обязательная проверка обычных CUnity/CAnimation объектов также прошла.
Точная новая production PE прошла обычный WinMain, TCP fixture, engine/D3D,
Character и существующий Create с eax1; отладчик остановил её до игрового цикла.
Это не вход в игру и не аутентификация455. Старые широкие suites не повторялись.
