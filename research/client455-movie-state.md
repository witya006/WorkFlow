# Состояние RTMovie, полосы экрана и FOV — участок 077

Восстановлены положительные флаги RTMovie 455 и их реальные потребители в
движке. Intro использует эти вызовы вместе с fullscreen-проходом 076.
Полный RVP-проигрыватель и обычный CGP_Tutorial пока не восстановлены.

Высота изображения: int(double(float(0.55))*screenWidth); высота полосы:
(screenHeight-imageHeight)/2 с целочисленным делением. На явном 640×480
верхняя полоса занимает строки 0–63, нижняя 416–479. Логотип располагается
на строках 400–466 и перекрывает часть нижней полосы: этот порядок сохранён.
DrawLogo в старом исходнике уже соответствовал проверенной геометрии и цвету.

Первоначальное имя cameraControlFlags в intro-host сохранено для совместимости
его интерфейса; фактический контракт — состояние RTMovie, а не произвольные
флаги управления камерой. Старый RTMovieSetState/GetState из 0.7 оставлен
отдельным переходным API с инверсными NO_* запросами. Его неперенесённые
вызывающие методы не объявлены соответствующими 455.

## Восстановленный исходник и проверка

Новые client455_movie_state.h/.inc реализуют состояние вне #ifdef RTMOVIE.
Производные rtmovie.cpp и r3util.cpp довели количество overlays до девяти;
в движке осталось 67 TU. Базовые исходники и библиотека 033 не изменены.
В r3d3d8.cpp разделены default/current FOV и убрано старое wide-изменение
viewport в обычном/main-FSE домене. MainApp.LoadData сбрасывает FOV в 0.6.

Собственный native/GPU probe прошёл восемь сочетаний флагов, сохранение старших
битов, отдельный полный запрос, raw Add/Remove без побочных эффектов и сброс
проекции: default 0.73 при current 1.1. Шесть кадров проверяют полосы/логотип
с fullscreen-эффектом и без него. Логотип в этой проверке — собственная
оранжевая текстура; это не проверка оригинального графического ресурса 455.

Три настоящих учебных мира повторно прошли 26 камер, fade/skip/reload и реальный
movie-state backend: Bellato 357, Cora 325, Accretia 258 ticks. Dmalloc до/после
270592, предупреждений 0, естественный exit 0. Проба fullscreen 076 повторно
прошла 18 кадров на текущем движке. Просмотрены 40 сохранённых кадров
(6 movie + 29 intro + 5 fullscreen). Запись stage-input/QBI/follow в intro-probe
остаётся тестовым наблюдателем; полноценного игрового провайдера здесь нет.

## Подтверждённый незакрытый разрыв

Настоящий проигрыватель находится внутри #ifdef RTMOVIE старого rtmovie.cpp,
но текущая конфигурация этого define не содержит. В собственной связанной
пробе RTMovieFrameMove имеет RVA 0xcefe0, первые байты
`558bec5dc3cccccccccccccccccccccc`: пустая функция с frame-pointer prologue.
Это прямое подтверждение заглушки, а не предположение по имени файла.
У Bellato есть настоящий .rvp с секцией [Object]; утверждение об отсутствии
RVP-ресурсов было бы неверным. Простое включение старого define не доказывает
совместимость track/actor/audio/Character API с 455. Их восстановление обязательно.

В прямой fixture InitR3D3D обнаружено screenHeight=500 при viewportHeight=480.
GPU-проверка явно задаёт 640×480 и проверяет этот домен; сам wrapper этим
участком не исправлен. Согласованность размеров окна/viewport остаётся открытой.
