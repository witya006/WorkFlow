# Проверяемые результаты

Для каждого вывода указывать:

- статус: факт / гипотеза / опровергнуто;
- SHA-256 исследованного файла и его путь в манифесте;
- RVA, image base и имя функции, если речь о машинном коде;
- путь и символ старого исходника;
- доказательство: ссылки, дизассемблер, наблюдаемое поведение или проверка;
- ограничения и следующий способ проверки.

Совпадение строк или похожий псевдокод сами по себе не доказывают эквивалентность.
Протоколы, структуры файлов и структуры в памяти описывать раздельно.
