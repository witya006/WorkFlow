# GoMMO: проверка клиентского инструментария, 14.11.2026

По запросу пользователя выполнено реальное подключение MCP через stdio
`gommostudio.exe -mcp`, а не проверка конфигурационного файла.
Studio сообщает версию 2.0.1 и 663 инструмента. В списке native tools текущей
сессии GoMMO отсутствует; существующий Python bridge работает.

## Практический результат

- `map_status`: первоначально домашний экран, открытых документов нет.
- `map_open_client`: существующий work/client455-preview/runtime, без копии клиента;
  распознаны 2 карты за заявленные Studio 0,3 с, exact_match=false.
  Это распознавание формата редактором, не доказательство версии бинарника.
- `map_open_map(lobby)`: 15 объектов — 8 props, 4 sounds, 3 walls.
- `map_materials(animated=true)`: 28 материалов с параметрами мерцания,
  прокрутки, кадровой анимации. `map_list_objects`: восемь cir_fire02/cir_fire03.
- `map_layers`: доступны слои геометрии, объектов и прочего для изоляции.
- Снимок получен через MCP и визуально просмотрен:
  artifacts/gommo-lobby-inspection.png. Это окно редактора 673×656,
  не игровой прогон и не проверка Full HD.
- Последний map_status: unsaved_edits=false, undo/redo пусты, сервер не связан.
  Studio создала собственный Scratch/rf455-448a11e5 в AppData; полного
  копирования клиента наша проверка не выполняла.

## Вывод и границы

Для просмотра ресурсов и получения готовых структур GoMMO сокращает отдельные
скрипты и ручные поиски. Использовать сначала её подходящий инструмент, если
он возвращает необходимые данные. Численной экономии времени/токенов пока
не измерено; число инструментов само по себе её не доказывает.

Просмотрщик показывает старое небо и собственный свет. studio_game_look читает
R3Engine.ini, помечает часть параметров unverified и считает bloom отключённым,
тогда как собственная сборка имеет новый проход bloom. Следовательно, его
картинка не подтверждает работу наших новых теней, материалов или неба.
Заявленного инструмента отладки произвольных C++/HLSL проходов нашего bin
в просмотренных схемах не найдено. Окончательная проверка — полный клиент.

Текущая качающаяся тень при выборе персонажа не исправлена этой проверкой.
GoMMO пригодна для изучения кандидатов в геометрии/эффектах; причина требует
измерений непосредственно в текущем рендере.

## Воспроизводимость

scripts/Invoke-Python.ps1 scripts/probe_gommo.py выполняет только handshake,
tools/list и studio_status. Опциональные `--call` принимают JSON вызова из
ограниченного списка клиентского исследования; использовать только после
прочтения актуальной схемы. Открытие другого клиента может сохранять текущий
проект: сначала map_status, не переключаться поверх несохранённых правок.
Не вызывались сохранение ресурсов, установка, публикация или серверные действия.

Схемы: inventory/gommo-mcp.json. Полученные ответы:
inventory/gommo-client-inspection.json (одна актуальная запись на имя метода,
без встроенных изображений). Скриншот один, путь повторно используется.
