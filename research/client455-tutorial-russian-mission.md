# Финальное задание русского обучения 455

Штатный `DataTable/ru-ru/bw.scp` воина Беллато. После главы добычи идут
32 команды `TutorialMission`. Они размещают десять монстров кода
`0x4401` в двух рядах, показывают цель, ждут десять подтверждённых
побед и проигрывают поворот камеры. Последнее сообщение ждёт
подтверждения. [Предыдущий этап](client455-tutorial-loot.md).

## Игровой контракт

Эталон x86, база `0x400000`, SHA-256
`b1b5febf0d0394712e2322350e19dafe60742e8642697b93cfb89135bac1fd8b`.
Условие QBI39 по RVA `0x29440` сравнивает счётчик с порогом сценария.
RVA `0x27880` связывает указатели контекста и его владельца. Локальный
результат боя по RVA `0x1647d0` увеличивает тот же счётчик после
гибели цели. Панель обучения использует существующий финальный диалог
и переход в мир. [Общий маршрут завершения](client455-tutorial-mission.md).

Учебный бой переиспользует выбранную цель, дальность оружия и движение
по локальному пути. Удар вне дальности сначала запускает подход.
Выбор другого объекта отменяет ожидающий удар по прежней цели. Счётчик
принимает результаты из учебной сцены.

При подборе клиент проецирует центр границ предмета и проверяет,
перекрывает ли его панель обучения. Если окно можно сместить, оно
освобождает точку подбора. После подбора следующая страница возвращается
на исходное место. Клик использует ту же проверку границ предмета, что
и раньше. Отдельная телеметрия доступна в проверочной сборке при
явном включении наблюдения.

## Соединение во время урока

На сборке `0f772d89…` подтверждены десять побед, поворот камеры и
закрытие финального диалога. Сервер закрыл сессию после пяти минут без
пакетов. Запрос выбора персонажа после диалога получил отказ отправки.

Панель 455 по RVA `0xa5d40` запрашивает периодическое сообщение
`1/17` после интервала строго больше 60 секунд. Общий таймер теперь
проверяется и при обновлении панели без пользовательского ввода.
Сообщение идёт через существующий маршрут учебного клиента. Тело
состоит из одного байта, как у эталона. Новый клиент инициализирует
его нулём, поскольку отправитель 455 оставляет значение
неопределённым. [Исследование панели](client455-tutorial-board.md).

Сборка `22f3ab08…` повторно прошла десять целей через обычный выбор и
Пробел. Журнал фиксирует подход по локальному пути, поворот камеры и
ожидание Enter в финальном диалоге. Сервер получил четыре сообщения
`1/17` и запрос выбора персонажа через 312 секунд после запроса списка.
Клиент загрузил NeutralB и завершился с кодом 0. Состояние новичка
выставлялось в отдельном тестовом процессе.

В этом прогоне панель уже переместилась вверх, но продолжала захватывать
весь экран. Диагностика зафиксировала её идентификатор 38 у всех кликов
в районе предмета. После Пробела предмет оказался в сумке. В сборке
`2f9921b0…` страницы подбора снимают этот захват, сохраняя обработку
кнопок внутри окна. Клик по пустому месту не подобрал предмет. Клик
по проекции модели (396, 427) перенёс его в первую ячейку, QBI11
завершилась по пустому контейнеру. Последующая страница вернула окно
на исходную позицию. Явный выход загрузил NeutralB, код завершения 0.
[Манифест](../inventory/client455-tutorial-russian-mission-checkpoint.json).

Открыты читаемость самой модели на земле, полный инвентарь, тайм-аут QBI11,
сохранение завершения обучения между сеансами и остальные профили.
