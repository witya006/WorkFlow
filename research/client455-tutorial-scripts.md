## Формат

Начало файла — DWORD числа заданий. Каждое задание: DWORD ID, 64 сырых байта
имени, WORD числа команд. Каждая команда начинается отдельным BYTE селектора.

| Селектор | Данные после селектора |
|---|---|
| 0–3 | BYTE dataType, WORD ID, сообщение с форматированными строками |
| 4 | 16 байт QBI_MESSAGE_DATA |
| 5 | 12 байт QBI_WAIT_DATA |
| 6–8 | 20 байт QBI_MOVE_DATA |
| 9–11 | 24 байта QBI_CREATION_DATA |
| 12–18 | 20 байт QBI_POSITION_DATA |
| 19–22 | 8 байт QBI_UI_DATA |
| 23–26 | 12 байт QBI_UI_EQUIP_DATA |
| 27–34 | 20 байт QBI_CURSOR_DATA |
| 35–39 | 20 байт QBI_COMBAT_DATA |
| 40–46 | 12 байт QBI_ITEM_DATA |

В фиксированных данных type находится по смещению0, ID WORD — по смещению2.
Селектор и сохранённый dataType — разные поля; parser не требует их равенства.
Неизвестные пока члены и padding фиксированных записей сохраняются побайтно.
Их назначение и исполнение нужно восстановить перед игровой интеграцией.

Сообщение: DWORD ID, три BYTE levelMin/levelMax/map, три DWORD action/time/display,
BYTE количества строк. Строка: 12 байт HSD_FONT, WORD длины, затем сырые байты.
Кодировка, embedded NUL, ненулевые padding и произвольные значения display
сохраняются; данные не перекодируются и не нормализуются.

## Проверенные входы

99 файлов с двухбуквенными именами из девяти языковых папок: 812 заданий,
39864 записей команд, 36818 строк и 1471548 байт текста. Это объём прочитанных
данных, не процент готовности и не число запросов к ИИ. В реальных файлах
встречаются 37 селекторов; отсутствующие 17/18/22/28/30/31/33/34/43/45 покрыты
искусственным файлом, содержащим все47 вариантов.

`DataTable/ko-kr/Tutorial.scp` не соответствует этому reader: чтение расходится
на смещении1215 с длиной8365 при размере4742. Его происхождение и совместимость
не установлены. Подтверждённый formatter A5EC0 не создаёт такое имя. Файл
сохранён отдельной записью аудита, C++ parser тоже отклоняет его без изменения
прежнего документа. Это не основание удалять или переименовывать его.

## Проверка и границы

MSVC x86 собрал самостоятельную библиотеку RF455TutorialScripts.lib
SHA-256 `4522a59bafa3397ccb31d610628480675bb4db4308c9fadf1dae98ef818684cd`.
Собственная проверочная PE `c3243ee3...`, entry RVA `BB30`, завершилась естественно0.

Для всех99 файлов decode→encode дал полное равенство байт. Имена, ID, type,
поля сообщений, fonts и bytes строк отдельно сверены с независимым Python
обходом через семантическую сериализацию. Искусственные примеры проверяют все47
селекторов, несовпадающие selector/dataType, изменение ID/type, нулевые строки,
длину65535, пустой документ и trailer. Все1069 неполных префиксов небольшого
примера отвергнуты с сохранением прежнего документа. Неверные selector/count,
размеры фиксированных данных и переполнение длины/числа строк проверены отдельно.

Ошибочные входы обрабатываются атомарно. Target делает непроверенные fread и
может оставить частично изменённый объект. Эти небезопасные области, а также
исчерпание памяти и вся семантика исполнения команд не выданы за соответствие.

Производственная RF_Online.bin и её библиотеки в057 не менялись. Общие большие
наборы проверок неизменённого клиента не повторялись. Здесь требуется проверка
нового загрузчика; запустить старый ProcessQuest на новых кодах было бы ошибкой.
