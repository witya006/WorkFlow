## Ожидания и порядок работы

Созданы собираемая база и значительный набор отдельных реализаций. Рабочего
игрового клиента 455 ещё нет. Прежние отчёты слишком выделяли число локальных
проверок; оно не показывало продвижение игрового сценария.

4. **D:** цель, атака, умение, предмет, чат через обычные обработчики — не пройдено.
5. **E:** остальные функции, варианты, ошибки и финальная M9 — не принято.

Ближайшее: реальные классы Avatar, экипировка, внешний вид
и оставшуюся загрузку для B. Не обходить загрузку и не принуждать успех входа.
