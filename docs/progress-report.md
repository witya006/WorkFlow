неизменённые большие наборы проверок не повторяются без причины.

При центральной оценке остаётся примерно втрое больше функционального объёма,
чем уже восстановлено. Это не множитель дней: интеграция и неизвестные участки
могут оказаться значительно труднее уже закрытой основы. Честной даты M9 пока нет.
