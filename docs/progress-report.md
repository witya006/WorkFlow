# Оценка восстановления клиента RF Online 455

Актуально на 10.11.2026. Только клиент; серверные исходники — справочник.
Цель M9: поддерживаемые исходники и собственный RF_Online.bin с полным
функционалом и поведением закреплённого 455, без модернизации графики.

**Плановая готовность: около 25%, разумный диапазон 20–35%.
Остаток: около 75%, диапазон 65–80% известного функционального объёма.
Сейчас M6. Полностью принятых функциональных областей: 0 из 12.**

Это оценка по подсистемам, а не измеренный процент восстановленных функций BIN.
Неизвестные особенности 455 могут увеличить объём. Оценка не означает, что
четверть времени уже потрачена или что оставшееся займёт ещё три таких периода.

Практический вывод: имеющихся исходников, бинарных эталонов и инструментов
достаточно, чтобы продолжать восстановление; выбранная конфигурация собирается.

Полнота ресурсов и спецификации поведения пока не установлена. Назначать им
условные90% или100% означало бы выдавать предположение за результат проверки.

IDA обнаруживает в закреплённом эталоне 37 865 функций, включая 1296 библиотечных.
