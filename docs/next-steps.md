## 3. Следующий результат: первая воспроизводимая сборка (M1)

1. Найти установочные материалы VC6/SP6 и SDK, подтвердить доступную VM.
   Зафиксировать версии/хеши составляющих среды и снимок VM.
2. Подготовить под work/legacy-build копию серверного дерева, сохранив байты и пути.
   Использовать внешний RF_Server/LoginServer; выходы оставить внутри work/legacy-build.
3. Собрать LoginServer Win32 Debug с исходными флагами. Команды/журналы в artifacts/,
   в Git только очищенная сводка. Ошибки исправлять минимальными патчами в копии.
4. Проверить compiler/linker exit 0, PE x86, импорты и повторную чистую сборку.
   Запуск/БД не входят в критерий compile/link; входные EXE не выполнять.

Если toolchain недоступен, зафиксировать конкретно недостающий дистрибутив и
продолжать доступную статическую работу M2, не повторяя весь аудит.

  оригинальным сервером CCR и не принимать всё его поведение за эталон.
