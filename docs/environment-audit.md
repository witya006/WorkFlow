## Открыто

Сборка с пустого выходного каталога после реорганизации ещё не воспроизведена;
workspace.py build использует сохранённые зависимости. Для части старых probes
нужны архивные входы: запускать их только по технической необходимости.
Полный игровой цикл, 12 областей и визуальный ориентир не приняты.
Состояние сервера/MCP в этом пакете не перепроверяли.

Оригинальный клиент и сервер находятся вне WorkFlow, по config/paths.json.
Очистка их не затрагивала. Git хранит авторский код/скрипты/малые доказательства;
игровые ресурсы, IDA и локальные зависимости сохранены на диске и исключены из Git.
