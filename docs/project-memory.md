# Память проекта

Обновлено 14.11.2026. Текущий этап M6; организационный пакет BASE-01 выполнен.
Основная цель снята/приостановлена по указанию пользователя и не возобновлена.
Текущий запрос разрешил очистку и планирование, а не новую серию игровых исправлений.

## Решения

- Только клиент RF Online, R3Engine и клиентские зависимости. Сервер — справочник
  и предоставленная среда проверки; не изменять его код, настройки или базы.
- Сохранить M0–M6, историю Git, восстановленные модули и проверенную сборку.
- Развивать поддерживаемый клиент, без формального воспроизведения технических
  недостатков 2000-х. Полнота игры и визуальный результат — отдельные критерии.
- Визуальный ориентир: Clair Obscur: Expedition 33, стиль RF сохраняется.
  Сначала картинка, глубокая оптимизация позже. Время кадра/память — диагностика.
- Будущие CW-профили 500/1000/2500 участников; визуальная толпа не доказывает сеть.
- Текущая платформа x86/D3D9, VS 2026 Professional. D3D11 пока кандидат для
  ограниченного эксперимента. Перенос на UE5 и массовая перепись не планируются.
- Проверять в 1920×1080, минимум 1280×720 с объяснением. Обучение не приоритет.
- Настройки: Звук, Изображение, Графика, Игра, HUD. Подписи понятны игроку.
- Git только локальный, без push. Секреты и игровые ресурсы в Git не добавлять.
