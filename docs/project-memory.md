# Память проекта

Обновлено 14.11.2026. Текущий этап M6; BASE-01 и BASE-02 выполнены. VIS-01 открыт.
14.11 пользователь возобновил разработку: закрепить сборку, затем показать
улучшенную опорную сцену lobby в 1920×1080 с максимумом качества Direct3D9.
Ориентир Expedition 33; глубокая оптимизация позже. Смена API сейчас не нужна.

## Решения

- Только клиент RF Online, R3Engine и клиентские зависимости. Сервер — справочник
  и предоставленная среда проверки; не изменять его код, настройки или базы.
- Сохранить M0–M6, историю Git, восстановленные модули и проверенную сборку.
- Развивать поддерживаемый клиент, без формального воспроизведения технических
  недостатков 2000-х. Полнота игры и визуальный результат — отдельные критерии.
- Визуальный ориентир: Clair Obscur: Expedition 33, стиль RF сохраняется.
  Сначала картинка, глубокая оптимизация позже. Время кадра/память — диагностика.
- 14.11 пользователь прислал конкретный ориентир lobby: станция над облаками,
  крупные планеты, звёзды, тёплый горизонт и холодная подсветка металла.
  Копия: artifacts/visual-target/lobby-space-reference.png. Это цель следующего
  художественного пакета, не снимок уже работающего рендера. Станция и камеры
  остаются 3D; дальнее окружение можно подготовить отдельно от геометрии и UI.
- Будущие CW-профили 500/1000/2500 участников; визуальная толпа не доказывает сеть.
- Текущая платформа x86/D3D9, VS 2026 Professional. D3D11 пока кандидат для
  ограниченного эксперимента. Перенос на UE5 и массовая перепись не планируются.
- Проверять в 1920×1080, минимум 1280×720 с объяснением. Обучение не приоритет.
- Настройки: Звук, Изображение, Графика, Игра, HUD. Подписи понятны игроку.
- По указанию пользователя 14.11 улучшенные lobby/небо и свет персонажей включены
  по умолчанию; явный выбор классики в меню сохраняется. Запрос «запусти клиент»
  означает полный игровой клиент с локальным сервером, не offline просмотр.
- Git только локальный, без push. Секреты и игровые ресурсы в Git не добавлять.

## Что подтверждено

Текущая сборка: work/client455-port/normal/build/RF_Online.bin,
SHA-256 ea6bf62950e2694f2cef550caf3bc7d6e92c0b55a50918ddce2b66ca9bb381c5,
x86, base 0x400000, entry RVA 0x1b47c0. Пересборка без ошибок; полный клиент
прошёл вход и три занятых слота lobby в 1920×1080 на локальном сервере. Это не
повторная приёмка мира. Все три персонажа читаемы; двойное затемнение убрано.
Тени 4096²: 89 групп BSP / 58 частей персонажей, ошибок новых проходов нет.
Облака подробнее, 512 отсчётов в 4×128 без полос прежнего редкого расчёта.
Применение/отмена/сохранение качества и пересоздание ресурсов проверены.
[Текущий пакет и ограничения](../research/client455-lobby-shadows.md).
Удаление исправлено по протоколу 455 и проверено настоящими обработчиками на
контролируемых ответах; живое удаление экипированного персонажа не проверяли.
Текущий игровой runtime: work/client455-preview/runtime, повторно используется;
настройки не сбрасываются при включении звука. Графические ключи отсутствовали
при первом запуске 373c4cdb: применяются новые значения по умолчанию из кода.
Ранее проверенная живая база 102a2443 сохранена как откат; её коммит 95baebf.
Чистая компиляция клиентских объектов с сохранёнными зависимостями прошла (180,62 с).
Новый свет непрозрачной BSP, FP16 обработка/свечение, MSAA4 и режимы настроек
проверены на одинаковой камере lobby. Это первый пакет, не максимум Direct3D9
и не соответствие Expedition 33. [Доказательства](../research/client455-lobby-visual.md).
По следующему замечанию пользователя старое небо улучшенной lobby заменено
атмосферой и объёмными облаками с внутренним затенением. Шум создаётся в памяти
(1 MiB), без новых текстурных файлов; классика сохранена. Графическая стоимость
заметна, полноценный профиль производительности ещё не снимался.

Есть вход в NeutralB, движение/остановка, отдельные боевые сценарии и Return,
анимация, сглаживание, ограниченный улучшенный свет, пять вкладок настроек.
Последний живой пакет настроек: inventory/client455-live-settings.json.
Реальная модель: inventory/client455-enhanced-actor.json. Границы приёмки:
[пакет света/настроек](../research/client455-modern-settings-lighting.md).

Пользователь подтвердил корректные ролики без мерцания и сохранение координат.
Полупрозрачность аватара объяснена предметом невидимости; предмет снят,
но повторный живой прогон непрозрачного аватара не выполнен. Невидимость не ломать.
