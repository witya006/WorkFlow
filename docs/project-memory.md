Обновлено 14.11.2026. Текущий этап M6; BASE-01 и BASE-02 выполнены. VIS-01 открыт.

## Решения

- Только клиент RF Online, R3Engine и клиентские зависимости. Сервер — справочник
  и предоставленная среда проверки; не изменять его код, настройки или базы.
- Сохранить M0–M6, историю Git, восстановленные модули и проверенную сборку.
- Развивать поддерживаемый клиент, без формального воспроизведения технических
  недостатков 2000-х. Полнота игры и визуальный результат — отдельные критерии.
- Визуальный ориентир: Clair Obscur: Expedition 33, стиль RF сохраняется.
  Сначала картинка, глубокая оптимизация позже. Время кадра/память — диагностика.
- 14.11 пользователь прислал конкретный ориентир lobby: станция над облаками,
  крупные планеты, звёзды, тёплый горизонт и холодная подсветка металла.
  Копия: artifacts/visual-target/lobby-space-reference.png. Это художественная
  цель, не снимок уже работающего рендера. Станция и камеры
  остаются 3D; дальнее окружение можно подготовить отдельно от геометрии и UI.
- Сначала довести только lobby до одобрения пользователя; потом обсуждать другие
  карты. По лору это орбита Novus. Новая палитра: титан/графит/голубые акценты,
  тёплые двигатели; отказаться от преобладания жёлтой краски. FPS/HUD слева по центру.
- Будущие CW-профили 500/1000/2500 участников; визуальная толпа не доказывает сеть.
- Текущая платформа x86/D3D9, VS 2026 Professional. D3D11 пока кандидат для
  ограниченного эксперимента. Перенос на UE5 и массовая перепись не планируются.
- Проверять в 1920×1080, минимум 1280×720 с объяснением. Обучение не приоритет.
- Настройки: Звук, Изображение, Графика, Игра, HUD. Подписи понятны игроку.
- По указанию пользователя 14.11 улучшенные lobby/небо и свет персонажей включены
  по умолчанию; явный выбор классики в меню сохраняется. Запрос «запусти клиент»
  означает полный игровой клиент с локальным сервером, не offline просмотр.
- Git только локальный, без push. Секреты и игровые ресурсы в Git не добавлять.

## Что подтверждено

Текущая сборка: work/client455-port/normal/build/RF_Online.bin,
SHA-256 2e2a4afb1cd1dedc0c602082a29f2f0847411d8aa902f115ccf3666ab8a87ee9,
x86, base 0x400000, entry RVA 0x1b9040. 71 engine object / 182 client / 20 kernels,
линковка без ошибок. Полный клиент: вход, меню, полёт и три камеры выбора,
1920×1080/MSAA4. Сейчас один занятый слот и два пустых; не писать «три персонажа».
[Орбитальный пакет и ограничения](../research/client455-lobby-orbit.md).
Планета под станцией, конечная атмосфера, туманности/звёзды, титановая палитра и
отражения интегрированы в полный клиент. Тени 4096²: 89 BSP / 20 actor parts;
матрица меняется только при первоначальной установке, возраст позы 0 кадров,
ошибок сбора/проходов нет. Проверены все три камеры, без повторной приёмки мира.
Русское сообщение удаления — строка активного языкового пакета 0x20a;
Russia/Korea GUI/dispatch/callback tests PASS. Живых персонажей не удаляли.
HUD Apply/Cancel/persist и шесть фаз смены/возврата графики PASS.
Реальный адаптер RTX 2080 Ti/HAL подтверждён. Низкий FPS меню локализован:
Present ждал ~31–33 мс. Явный IMMEDIATE при VSync=0 (новый default) дал 64,3–65,0 FPS
вместо ~21,5 при прежних 1920×1080/MSAA4/4096² тенях/FP16. Present ~0,3 мс.
VSync=1/ONE отдельно проверен: ~26 FPS на этой машине, ожидание ~31 мс.
Переключатель в «Изображение», Apply/Cancel/persist проверены; нужен перезапуск.
HUD off/on и имя .exe/.bin просадку не объясняли. Глобальные настройки NVIDIA
не менялись. Восемь CPU/GPU секций и Present измеряются; GPU elapsed включает
возможные простои, его нельзя путать с занятостью. Дальнейший общий профайлинг
не приоритет: следующий пакет — художественная детализация lobby.
Поверхность планеты текстурная; материалы станции пока сохраняют исходную
детализацию. Результат не равен референсу и не объявляется максимумом D3D9.
Текущий runtime work/client455-preview/runtime повторно используется. Художественная
приёмка VIS-01 открыта; остальные карты не модернизировать до одобрения lobby.
